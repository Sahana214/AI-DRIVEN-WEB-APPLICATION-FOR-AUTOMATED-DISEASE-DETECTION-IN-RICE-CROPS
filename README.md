# AI Driven Web Application for Automated Disease Detection in Rice Crops
# 🌾 Rice Leaf Disease Predictor

An AI-powered web application that predicts rice leaf diseases from uploaded images using Deep Learning and Transfer Learning with MobileNetV2.

---

## 🚀 Features

- 🔐 User Login & Signup Authentication
- 🌱 Rice Leaf Disease Prediction
- 🖼 Upload rice leaf images (`jpg`, `jpeg`, `png`)
- 🤖 Deep Learning model using MobileNetV2
- 📊 Displays prediction confidence score
- ⚡ Built with Streamlit for interactive UI

---

## 🧠 Model Used

This project uses:

- **TensorFlow / Keras**
- **MobileNetV2 (Transfer Learning)**
- Fine-tuned custom classification model

---

## 📂 Dataset

The model was trained using a Rice Leaf Disease Dataset containing multiple rice plant disease classes.

Example disease categories:
- Bacterial Leaf Blight
- Brown Spot
- Leaf Smut

---

## 🛠 Tech Stack

- Python
- Streamlit
- TensorFlow / Keras
- NumPy
- PIL (Python Imaging Library)
- Pickle
